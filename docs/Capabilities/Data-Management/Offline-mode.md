***

CHEFS now supports saving submissions on a submitter's device while they are offline. Entries sync to the server automatically once the device is back online.

See **[Offline Submissions](../Functionalities/Offline-Submissions)** for how to enable it, what submitters see, and its limits.

If you need to work with data outside of CHEFS entirely, you can also:

* [Review importing data into CHEFS](Importing-data-into-CHEFS)
